# SToasts

A SwiftUI stacked toast notification example. Toasts are stacked using a `ScrollView` with the `visualEffect` API instead of a `ZStack`, with an adjustable glass tint opacity and optional auto-dismiss.

## Credits

This project follows the tutorial by **Kavsoft**:
[Stacked Toasts in SwiftUI (YouTube)](https://www.youtube.com/watch?v=4cLWzZ7_0Bk).
All credit for the original idea and approach goes to Kavsoft.

## Requirements

- Xcode (recent version with iOS 26 / Liquid Glass APIs)
- Open `SToasts.xcodeproj` and run.
